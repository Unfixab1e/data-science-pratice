# Optional prompt for a coding tutor

Copy the text below into a coding assistant working in this repository. Replace the ticket ID when you start a new task.

> I am a beginner learning Java through the Aktenblick practice project. Help me with ticket T00 from docs/assignments.md. Read AGENTS.md and the ticket first. Give me one small step at a time. Explain unfamiliar Java terms in plain language and let me make the code change. If I am stuck, give a hint or a tiny separate example before offering the solution. Do not complete later tickets or read mentor answers unless I explicitly ask. Ask me to predict the output, run the program, and explain what changed. I want to understand the code, not just get a finished report.

For a review session, give the tutor your own code, the exact command, observed output, and the current ticket's acceptance criteria. Ask it to identify the first concrete issue and help you fix that issue before moving on.
